# 拾遗 · save_anything

把随手存下来的东西,变成以后找得回来、记得起为什么的笔记。

丢一个 .txt/.md 到 inbox/,跑一下 ingest:AI 帮你提炼「是什么」(≤30 字摘要 + 2-4 个标签),你亲手写下「为什么存它」。笔记按结构化格式存进 notes/,原文件移进 archive/。想找的时候一句关键词搜回来;定期跑 resurface,系统把最久没看过的笔记递到你面前,问一句「现在还有用吗?」,回答记回笔记。

## 使用

```bash
# 1. 存:把想存的 .txt/.md 丢进 inbox/,然后:
python ingest.py
#    逐条:打印 AI 摘要/标签 → 让你写一句理由(回车跳过,标「(待补)」)

# 2. 找:
python search.py 关键词 [关键词...]
#    只搜 摘要/标签/理由,大小写不敏感,多词 AND,按保存时间倒序

# 3. 回顾:
python resurface.py
#    推出最久没看过的笔记,问「现在还有用吗?」,回答记回笔记

# 4. 前端「拾遗」:
python web.py
#    浏览器打开 http://127.0.0.1:8000,浏览 + 搜索 + 回顾都在页面上
```

## 配置

Python 3.9+,纯标准库,**无需安装任何第三方依赖**。

DeepSeek API key 两种给法(取其一):

- 环境变量:`set DEEPSEEK_API_KEY=sk-...`
- 或在项目根目录建 `config.env`,内容一行 `DEEPSEEK_API_KEY=sk-...`(已被 gitignore)

## 笔记格式

每条笔记一个 .md,头部是纯文本元数据,正文是原文全文:

```
---
标题: 原文件名
摘要: ≤30 字
标签: a, b, c
理由: 为什么存它(留空则「(待补)」)
保存时间: 2026-09-11 14:30
上次回顾: 最近一次被 resurface 展示的时间(缺失=从未)
---

<原文全文>
- [2026-09-11 14:31] 每次回顾追加一行:时间 + 回答
```

正文可以随便手改;头部改坏也不崩(按缺省元数据处理,下次回顾会自动重建头部)。

## 前端「拾遗」

```bash
python web.py              # 默认 http://127.0.0.1:8000
python web.py --port 9000  # 换端口
```

页面上能:浏览全部笔记(按保存时间倒序)、搜索(规则同 search.py)、点右下角「回顾」拾起最久没看的一条、把回答记回笔记。纯标准库 + 原生 HTML/CSS/JS,无构建、无第三方依赖,只监听本机 127.0.0.1。

## 编码注意事项(Windows)

- 以 **Git Bash / Windows Terminal** 为准;cmd + chcp 936 下提示文字可能乱码。
- 输入文件自动识别 UTF-8(含 BOM)与 GBK。
- 不要用管道把 GBK 编码的文本喂给脚本,交互输入中文请直接在终端打字。

## v1 已知限制

- 手动触发:无文件监听、无定时任务。
- 无数据库:笔记就是 .md 文件本身,搜索在内存里线性扫(个人量级足够)。
- 只处理 inbox 里的 .txt / .md。
- 发给 API 只取前 6000 字(笔记正文仍存全文),摘要质量取决于模型。
